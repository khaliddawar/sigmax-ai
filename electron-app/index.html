📈 SignalScope Overview

SignalScope captures trading signals and discussions from Circle.so and forwards them to Telegram. This desktop application provides a convenient way to manage the SignalScope server and monitor its status.

Version: 1.3.0
Features: Message Capture, Deduplication, Image Support
Platform: Circle.so → Telegram
